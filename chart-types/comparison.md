# Comparison charts

## Bars & columns
Use when: comparing values across categories.

- Use bars to compare values across categories.
- Keep bars vertical with a zero-baselined value axis and a clear category axis.
- Start the value axis at zero; never truncate a bar baseline.
- Use vertical columns when labels are short and few.
- Use horizontal bars when labels are long or numerous.
- Sort bars by value unless a natural or fixed order exists.
- Use clustered bars to compare multiple series within each category.
- Overlay a target reference line so viewers see who cleared or missed it.
- Add error bars to bars of estimates so viewers don't over-read small gaps.
- Keep exact value labels on stylized or illustrated bars so accuracy survives the metaphor.
- Collapse a long tail into an "Others" bar to focus on leaders.
- Keep bar spacing consistent and the value scale uniform.

## Dot & lollipop
Use when: many categories need precise comparison with less ink.

- Use a lollipop instead of long bars to cut heavy ink.
- Use a dot plot to compare values across many categories precisely.
- Sort dot or lollipop rows by value unless a natural order exists.

## Dumbbell
Use when: showing before/after for each category.

- Use a dumbbell to show before/after per category with paired dots.
- Encode the two dots as two shades of one hue for direction.
- Point every dumbbell the same way to signal a universal directional effect.
- Sort dumbbell rows by current value when readers look up individual items.
