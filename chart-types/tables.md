# Tables

- Use a table when precise values matter more than a visual.
- Embed inline mini-charts or sparklines in rows for detail plus trend.

## Reading & scanning
- Give tables more rows than columns; people skim vertically.
- Let readers scan both across rows and down columns.
- Sort rows by the most important value by default, never alphabetical.
- Scale row height to volume: airy for few rows, compact for many.

## Color & emphasis
- Use color to lead the eye to interesting values, not to decorate.
- Highlight the highest and lowest values in each column.
- Reuse consistent category colors across the table for orientation.
- Embed heatmap cells with one color gradient per measure.
- Use zebra shading only for many wide columns; skip it on narrow tables.

## Type & format
- Right-align numbers, align on the decimal, and use tabular figures so they line up.
- Narrow columns with abbreviations, icons, and shortened number formats.
- Lift repeated words out of column headers into one shared label.
- Add small inline visuals (icons, logos, sparklines) to speed scanning.

## Declutter & scale
- Keep borders and shading minimal so the numbers carry the table.
- Include only essential columns; drop any that don't serve the point.
- Add search, sortable columns, and pagination for long tables.
- Highlight the row of interest.
