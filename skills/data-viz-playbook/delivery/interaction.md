# Interaction

- Reveal exact values on hover; keep the default view uncluttered.
- Let users drill from summary to detail via click, not clutter.
- Let viewers toggle or click to isolate a single series or trend.
- Don't add interaction that clutters an already-simple chart.
- Keep interactive controls usable and sharp across phones and tablets.
- Provide filters for segment or region when aggregates hide local variation.
- Pair animation with pause and scrubbing controls so viewers can inspect key moments.
- For interactive charts, address the reader directly to prompt exploration.
