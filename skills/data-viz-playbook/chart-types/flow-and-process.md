# Flow & process charts

## Funnel
- Use a funnel to show progressive drop-off through sequential stages.
- Order stages by the real sequence; label the conversion rate between them.

## Sankey
- Use a Sankey to trace source-to-destination reallocation of a total.
- Flow in one direction with minimal crossings; size link width by volume.
- Limit nodes so the dominant paths stay legible.

## Waterfall
- Use a waterfall to show an initial value changing through sequential steps to a total.
- Anchor start and end as full columns; float and color intermediate rises and falls.
- Use one color for increases, another for decreases.
- Connect bars with horizontal lines; include a starting reference value.
- Avoid waterfalls with too many steps; they clutter.
- Use waterfalls for variance bridges: budget-to-actual or period-to-period drivers.
