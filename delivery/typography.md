# Typography

- Default to sans-serif for chart and table text; reserve serifs for titles.
- Avoid narrow, condensed, or very thin fonts; they strain and fade.
- Set body, labels, and annotations in regular weight for easiest reading.
- Build hierarchy from weight, size, and color — not many typefaces.
- Keep chart text at least 12px; smaller sizes get hard to parse.
- Set most text near-black; reserve grey for secondary detail.
- Start all text small and grey, then emphasize only what matters.
- Give titles the biggest, boldest, highest-contrast text.
- Emphasize within an element with bold, not a larger size.
- Use all-caps sparingly; add letter-spacing and slight weight when you do.
- Left- or right-align text; avoid centre alignment for a tidier look.
- Keep typography consistent between direct labels and legend entries.
- Choose fonts with lining, tabular figures so numerals share height and width and align.
- Verify text meets accessibility contrast ratios against its background.
