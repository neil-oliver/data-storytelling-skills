# Audience & presentation

## Tailor to the audience
- Frame every visual around the audience's context, priorities, and decisions; lead with what matters most to them.
- Filter to the three or four findings that inform the decision.
- Give each view one key idea, decision, or topic.
- For leadership, default to simple, quick-read charts; keep updates to one to three KPIs.
- Match detail and complexity to how broad the audience is.
- Match number precision to need: round for dashboards, keep decimals for finance and science.
- Only use forms needing taught reading (ternary, log) when the audience can learn them.
- Choose box plots for lay audiences; reserve KDE and violin for stat-literate ones.
- Anchor unfamiliar magnitudes against a universal comparison the audience already knows.
- Match chart form to venue: conventional for boardrooms, distinctive for scroll-stopping media.
- Let users filter by segment or region when aggregates hide local variation.

## Present it
- Lead with purpose so meetings end in clarity and action.
- Open a deck with a problem, then a data-backed solution, then a forecast.
- Storyboard the sequence so insights flow start to finish.
- Actively control where the audience looks; don't leave the key point unemphasized.
- Sanity check before publishing: is the most important thing clear in five seconds?
- State findings in confident language, not hedges like "kind of might maybe".
- Turn pushback into credibility by answering with composure.
- Pair fonts for legibility and professionalism across charts and slides.
- Match supporting-text format to context: bullets for slides, paragraphs for docs.

## Read charts critically
- Inspect axes and ranges before trusting a chart's visual message.
- Verify exactly what a chart measures; different metrics tell different stories.
- Cross-check the same figure across multiple reputable sources.
- Consider external factors before attributing a spike or dip to an obvious cause.

## Interaction
- Expose an arbitrary cutoff as an interactive slider rather than hard-coding one split.
- Offer an un-log toggle so viewers can inspect raw magnitudes behind a log view.
